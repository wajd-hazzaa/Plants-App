🌱 Planto

App Name & Purpose

Planto is a plant care reminder app that helps users organize and keep track of their plants in one place. It makes plant care easier by allowing users to manage watering reminders and track their daily progress.

Main Features

* Add Plants: Add a plant by entering its name and selecting its room, light requirements, watering frequency, and water amount.
* Edit Plants: Update plant information whenever needed.
* Delete Plants: Remove plants from the reminder list.
* Daily Progress: Track how many plants have been taken care of through a progress bar.
* Mark as Completed: Mark a plant as watered when its care task is completed.
* Local Notifications: Receive watering reminders to help maintain a plant care routine.
* Plant Organization: View all plants and their care details in one place.

Technologies Used

* Swift
* SwiftUI
* UserDefaults for local data storage
* UserNotifications for local notifications
* MVVM Architecture

Design

Planto features a simple dark interface with green accents, designed to provide a calm and easy-to-use plant care experience.
